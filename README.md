# スプナータイプ辛口診断

SPOONユーザー向けの非公式・ファンメイド診断データ。

## 構成
- `data/questions.json` : 25問・各5択
- `data/stats.json` : 12基本ステータス
- `data/types.json` : 20タイプの判定条件・結果文
- `data/messages.json` : 裏ステータス・シェア文
- `data/config.json` : 診断全体設定

## ブランド利用
公式ロゴを使用しない前提で、濃いオレンジ＋白のオリジナルデザインを推奨。
公式サービスとの提携・承認を示す表現は避ける。

## 判定
回答効果を集計→0〜100へ正規化→各タイプの適合度を計算→必須条件・ボーナス・優先順位を適用。
60未満のタイプは候補外。
